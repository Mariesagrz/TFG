# TFG
Códigos asociados al TFG, sincronización de osciladores acoplados Stuart Landau con ruido.

- pfd1.py : Representación de la función de distribucion de probabilidad de un solo oscilador
- un_osc_final.py : Representacion de amplitud y fase en el tiempo de un oscilador stuart landau con ruido
- transicio.py : Grafica (ref5, figura 11) visualizar el valor critico de 'a' para diferentes valores de ruido
- cuadricula.py: Cuadricula con mapa de calor para ver el estado final de cada oscilador en una red de N osciladores
- n_osc.py; Otra forma de ver las fases y amplitudes finales de la poblacion de los osciladores de forma mas sencilla
- parametros_n.py: Tambla con los valores estadisticos de media, desviacion y metrica de sincronia con el parametro de kuramoto segun el valor de acople y ruido.
